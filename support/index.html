Политика конфиденциальности

Обновлено: 22 октября 2026 года

Эта политика относится к приложению PUSHKA — доске объявлений. Контакт по вопросам обработки данных: milaniumkz@yandex.kz.

Какие данные используются

  • Данные, которые вы вводите: номер телефона, имя, выбранный город, язык и сведения профиля.
  • Пользовательский контент: объявления, описания, фотографии, сообщения, вложения, жалобы и обращения в поддержку.
  • Действия в приложении: избранное, сохранённые поиски, просмотры объявлений и настройки уведомлений.
  • Технические данные: идентификатор аккаунта, токен push-уведомлений, сведения об устройстве, события использования и диагностика сбоев, обрабатываемые подключёнными SDK Firebase.

Для чего нужны данные

Для работы аккаунта, публикации и поиска объявлений, общения пользователей, отправки уведомлений, обработки обращений, модерации контента, предотвращения нарушений и диагностики работы приложения.

Кому доступны данные

Содержание опубликованных объявлений и указанные в них контакты доступны другим пользователям. Переписки предназначены для участников; уполномоченная администрация может получать доступ для рассмотрения жалоб и модерации. Не размещайте в открытом объявлении сведения, которые не хотите сделать общедоступными.

Инфраструктура приложения использует Google Firebase и Google Cloud: Authentication, Firestore, Storage, Cloud Functions, Messaging, Analytics и Crashlytics. Контент может обрабатываться Google Vertex AI для автоматической модерации. Эти сервисы могут обрабатывать данные на серверах за пределами страны пользователя. Политика конфиденциальности Google.

Разрешения и управление данными

Фотографии и файлы выбираются по вашему действию. Уведомления можно отключить в настройках устройства. Данные профиля редактируются в приложении. Запрос на доступ, исправление или удаление данных можно отправить в поддержку.

Хранение и удаление

Блокнот осмотров хранит на вашем устройстве выбранные снимки объявлений, отметки чек-листа и личные заметки. Эти записи не отправляются в Firebase, продавцам или другим пользователям. Вход в аккаунт для блокнота не требуется. Запись можно убрать из блокнота; данные также удаляются при очистке данных или удалении приложения. Блокнот не синхронизируется между устройствами.

Данные аккаунта хранятся, пока они нужны для работы сервиса. После подтверждения удаления удаляются профиль, объявления, переписки, фотографии, вложения, избранное и сохранённые поиски. Обезличенные платёжные записи могут сохраняться для учёта. Если данные необходимо сохранить по закону, это ограничивается соответствующей обязанностью.

Временный способ входа

В первой версии код доступа показывается на экране; СМС не отправляется и владение номером не подтверждается. Профиль привязан к случайному секрету установки приложения, а не к номеру телефона. Ввод номера на другом устройстве не открывает существующий профиль. После переустановки или удаления данных приложения восстановить такой профиль через номер нельзя. Не представляйтесь другим человеком и не публикуйте чужие контакты. Для удаления данных без доступа к приложению обратитесь в поддержку.

Удаление аккаунта и данных

В приложении откройте Профиль → Удалить аккаунт → Удалить аккаунт и данные и подтвердите действие. Восстановить удалённые данные невозможно.

Без доступа к приложению отправьте запрос на milaniumkz@yandex.kz с темой «PUSHKA: удаление аккаунта». Укажите номер телефона аккаунта. Поддержка уточнит необходимые сведения для проверки принадлежности аккаунта; пароль и код входа отправлять не нужно.

Удаляются профиль, объявления, переписки, фотографии, файлы, уведомления, избранное и сохранённые поиски. Обезличенные платёжные записи могут сохраняться для учёта. Обработка запроса может занять некоторое время; при обращении через поддержку мы сообщим о результате после проверки.
